StudyPilot

Plan • Learn • Improve

An intelligent, transparent academic management system designed to eliminate student overwhelm by uniting performance tracking with intelligent task prioritization.

Created By: Devdeep rajbhar bcads13

The Problem

Students juggle test scores, lab assignments, homework, and exams across disparate notebooks and messaging groups. Without clear visibility, students frequently spend revision hours on topics they already know while missing impending deadlines.

The Solution

StudyPilot calculates subject health and deadline countdowns simultaneously, running a rule-based priority engine that creates a clear, actionable daily roadmap without convoluted setup.

Technology Stack

Python & Streamlit Core backend & prototyping
Pandas Academic analytics engine
Tailwind & Chart.js Clean client dashboard UI
Local CSV & Storage Zero-cloud offline persistence

Future Roadmap

  • Native Android/iOS companion application
  • Google Calendar two-way synchronization
  • Automated WhatsApp assignment deadline alerts
